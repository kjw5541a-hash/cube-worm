# 큐브 지렁이 — 배경음악과 효과음 설계

2026-10-13. 기존 스펙(`2026-10-06-cube-worm-design.md`)에 소리를 더한다. 지금 게임에는 소리가 전혀 없다.

## 목표

- 장난감 블록·젤리 같은 부드럽고 통통 튀는 소리. 짧고 작아서 오래 들어도 피곤하지 않다.
- 소리 파일은 **코드로 합성**한다(저작권 문제가 없고 저장소에서 다시 만들 수 있다). 마음에 안 드는 소리는 나중에 파일만 바꿔도 된다.
- 게임 규칙·화면 코드는 소리를 몰라도 된다. 소리는 이미 있는 신호(`ate`, `cleared`, 입력 신호)와 상태 전환을 듣는 한 곳에서 낸다.

사용자는 합성한 시안(효과음 12개와 BGM 15초)을 직접 듣고 "괜찮다"고 했다. 안 정한 두 가지는 아래 기본값으로 둔다. 다르게 원하면 알려 달라.

## 1. 소리 목록

| 이름 | 언제 | 소리 |
|---|---|---|
| `eat_0` `eat_1` `eat_2` | 벌레를 먹을 때(종류 0·1·2) | 올라가는 "뽁" + 짧은 "쩝". 음높이 392 / 523 / 698 Hz. 종류가 높을수록(점수가 클수록) 높다 |
| `turn` | ◀ ▶ 입력이 받아질 때 | 아주 작은 "톡" |
| `up` `down` | ▲ ▼ 입력이 받아질 때 | 올라가는 / 내려가는 "뽀옹" |
| `rotate` | 맵 회전 버튼 | 부드러운 "슥" |
| `die` | 죽을 때 | 낮은 "쿵" 뒤에 내려가는 소리 |
| `clear` | 레벨 클리어 | 짧은 3음 상승 |
| `start` | 대기 중 첫 방향 입력으로 출발할 때 | 가벼운 "뿅" |
| `skin` | 스킨 선택 변경 | 작은 "딸깍" |
| `bgm` | 늘 | C 장조 펜타토닉 8마디 루프, BPM 96, 약 20초 |

- **연속 먹기:** 2초 안에 이어서 먹으면 `eat_*` 의 음높이를 반음 두 개씩(최대 4단계) 올려 재생한다. 2초가 지나면 처음으로 돌아간다.
- **뺀 것:** 레벨별 BGM 템포 상승(선택 사항이었고 곡을 늘 같은 템포로 두는 편이 단순하다). 필요하면 나중에 `pitch_scale` 한 줄로 더할 수 있다.

## 2. 구조

새 파일은 둘이다. 나머지는 기존 파일에 한두 줄씩 연결한다.

- `scripts/audio.gd` — 클래스 `Sfx`(Node). 소리를 내는 유일한 곳이다.
  - 효과음용 `AudioStreamPlayer` 여러 개(동시에 겹쳐 울리도록 풀로 돌려 쓴다)와 BGM용 한 개를 가진다.
  - `play(id: String, pitch := 1.0)` — 효과음. 꺼짐 상태면 아무것도 안 한다.
  - `start_music()` — BGM 시작. 이미 재생 중이면 아무것도 안 한다.
  - `set_muted(on: bool)` / `muted` — 전체 켜짐·꺼짐. 꺼질 때 BGM도 멈추고, 켜질 때 다시 이어서 시작한다.
  - 연속 먹기 단계 계산은 정적 함수 `combo_pitch(step: int) -> float` 로 빼서 헤드리스에서 검사한다.
- `assets/audio/*.ogg` — 소리 파일. 웹·모바일에서 용량이 작도록 OGG Vorbis.
- `tools/audio/synth.py` — 소리를 합성해 `assets/audio/` 에 쓰는 스크립트(표준 라이브러리만 사용). 시안 스크립트를 정리한 것이다.

### 연결 (`scripts/main.gd` 가 이미 모든 입력·신호를 받는다)

| 소리 | 연결 지점 |
|---|---|
| `eat_*` | `game.ate(kind, …)` 의 `_on_ate` |
| `turn` `up` `down` `start` | `_on_steer` 에서 `game.press()` 가 `true` 를 돌려줄 때(받아진 입력만). 대기 → 실행 전환이면 `start` |
| `rotate` | `_on_turn` 에서 회전이 실제로 시작될 때 |
| `die` | `_process` 의 죽음 전환 처리(`_was_dead` 가 처음 켜질 때) |
| `clear` | `game.cleared` |
| `skin` | `picker.skin_changed` |
| BGM 시작 | 첫 입력 때(아래 웹 제약) |

BGM 은 죽은 직후 `DEATH_DELAY` 동안 볼륨을 반으로 줄였다가 다시 올린다(음이 끊기지 않는다).

## 3. 켜짐·꺼짐과 저장

- HUD 오른쪽 위, 회전 버튼 옆에 소리 버튼 하나. 누르면 효과음과 BGM 이 함께 켜지고 꺼진다. 아이콘은 한글 폰트에 없을 수 있어서 `TurnButton` 처럼 직접 그린다(스피커 + 파동 / 스피커 + ✕).
- 상태는 `SaveData`(`user://cube_worm_save.cfg`)에 저장하고 다음 실행에도 유지한다. 기본은 켜짐.
- 효과음·BGM 음량을 따로 조절하는 UI 는 두지 않는다. 음량은 합성 때 정해 두고, 둘을 따로 끄는 버튼도 만들지 않는다(필요하다는 말이 나오면 그때 더한다).

## 4. 웹 제약

브라우저는 사용자의 첫 터치·키 입력 전에는 소리를 막는다. 그래서:

- BGM 은 첫 입력(조향·회전·스킨 선택·소리 버튼 중 아무거나)에서 시작한다. 화면을 연 직후에는 조용하다.
- Godot 웹 내보내기의 오디오는 사용자 입력 안에서 재생을 시작하면 풀린다. 별도 처리는 하지 않는다.

## 5. 테스트

- `tests/test_audio.gd`:
  - `Sfx.combo_pitch`: 0 단계는 1.0, 단계가 오를수록 커지고 4단계에서 멈춘다.
  - 켜짐 상태에서 `play` 는 풀의 플레이어를 쓰고, 꺼짐 상태에서는 쓰지 않는다. 같은 소리를 빠르게 여러 번 불러도 오류가 없다.
  - `set_muted(true)` 는 BGM 을 멈추고 `false` 는 다시 시작한다. 이미 재생 중일 때 `start_music()` 을 또 불러도 다시 시작하지 않는다.
  - 파일 목록: 소리 이름마다 `assets/audio/<이름>.ogg` 가 있고 불러와진다.
- 소리 켜짐 값이 `SaveData` 에 저장·복원되는지 검사한다(기존 저장 테스트가 있으면 확장).
- `tests/test_main_smoke.gd` 확장: 벌레를 먹으면 `eat` 소리가 풀에서 재생된다. 소리 버튼을 누르면 꺼진다. 헤드리스에서는 실제 소리가 나지 않으므로 "어떤 플레이어가 어떤 스트림으로 재생 상태인가"만 본다.
- **귀로 듣는 판단**은 자동 테스트로 할 수 없다. 웹 빌드를 폰에서 듣고 판단한다(아래 7절).

## 6. 만드는 순서

1. `tools/audio/synth.py` 정리 → `assets/audio/*.ogg` 생성(WAV → OGG 변환 도구가 없으면 Godot 가 WAV 도 읽으니 WAV 로 두고 용량만 확인한다).
2. `Sfx` 와 테스트.
3. `main.gd`·HUD·`SaveData` 연결, 스모크 테스트.
4. 브랜치 `audio` 푸시(Pages 배포) → 폰에서 듣기.

## 7. 플레이로 판단할 것

- 소리 크기 균형(효과음이 BGM 에 묻히지 않는지, 반대로 BGM 이 귀찮지 않은지).
- 20초 루프가 반복돼도 질리지 않는지. 질리면 곡을 늘린다.
- "톡" `turn` 이 너무 자주 들려 거슬리지 않는지.
- 웹에서 첫 입력 전에 조용한 것이 어색하지 않은지.
